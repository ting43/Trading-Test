# Trading-Test

這是一個股票交易策略回測與機器學習預測的專案，包含三種不同的交易分析方法。

## 專案架構

### 1. Strategy - 傳統技術分析策略
**標的股票**: 聯電 (2303)  
**回測期間**: 2020-01-01 ~ 2024-12-31

#### 策略說明
使用傳統技術指標進行交易決策：
- **移動平均線交叉**: 5日短均線與20日長均線的交叉作為買賣訊號
- **ATR濾網**: 當ATR低於閾值(1.2)時才允許交易，避免高波動行情
- **成交量確認**: 當日成交量需大於5日平均成交量
- **加碼機制**: 持倉時遇到5日新高則以開盤價加碼

#### 績效指標
- 勝率、交易次數
- 獲利因子、賺賠比
- 最大回撤 (MDD) 與最大回撤百分比
- 累計損益

---

### 2. XGBoost - 機器學習預測
**標的股票**: 英業達 (2356)  
**資料期間**: 近五年日資料

#### 策略說明
使用XGBoost回歸模型預測下一交易日的報酬率：
- **特徵工程**: 包含多個技術指標
  - EMA (5~95日指數移動平均)
  - William %R (威廉指標)
  - RSI (相對強弱指標)
  - OBV (能量潮指標)
- **預測目標**: 下一個交易日的報酬率(%)
- **交易規則**: 預測報酬率 ≥ 2% 買進，預測報酬率 ≤ -2% 賣出

#### 回測方式
使用 `backtesting.py` 套件進行策略回測，輸出包含：
- 報酬率、夏普比率、索提諾比率
- 最大回落、勝率
- 交易次數與期望值

---

### 3. 深度學習 - LSTM 神經網路預測
**標的股票**: 台積電 (2330)  
**資料期間**: 2007-04-01 ~ 2025-03-28

#### 策略說明
使用LSTM (長短期記憶網路) 預測股價走勢：
- **技術指標特徵** (共18種):
  - TR、ATR_20
  - SMA (5, 10, 20日簡單移動平均)
  - EMA (5, 10, 20日指數移動平均)
  - KD指標 (K值、D值)
  - RSI_14、OBV、MACD
  - DMI指標 (PLUS_DI、MINUS_DI、ADX)
  - William %R
- **資料預處理**: MinMaxScaler 標準化
- **資料分割**: 訓練集 70% / 測試集 15% / 驗證集 15%
- **預測目標**: 下一交易日的報酬率
